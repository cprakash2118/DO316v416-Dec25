Introduction to OpenShift Virtualization
Figure 1.2: Containerizing KVM

RHV (Red Hat Virtualization) - OLD:-
- KVM runs directly on host.
- Kernel Based Virtual Machine (It's a hypervisor - which allow to create VMs).
- All hosts/VMs managed by RHV-M 
- RHV-Manager send instruction to VDSM (Video Display Server manager - agent)
- Libvit -> Define the VMs 
- QEMU -> Qemulater 
- KVM -> Kernal Based Virtual machine is an hypervisor which allow to create VMs (defined by libvirt)
  and qemulated by QEMU.

Example:-
- Admin create VMs from RHV-M
- RHV-M send instruction -> vdsm 
- vdsm instructs libvirt
- Libvirt start the VMs using QEMU/KVM.
- VMs' runs on RHV hots hardware.
